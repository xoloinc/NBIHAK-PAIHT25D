# Kunskapkontroll 3

## EDA (Exploratory Data Analysis) - Snabb förklaring:
### Vad är det?
Utforskande dataanalys - processen att undersöka och förstå din data INNAN du bygger modeller eller drar slutsatser.

### Målet:

Förstå datastrukturen
Hitta mönster och samband
Identifiera problem (saknade värden, outliers)
Få insikter om vad som påverkar vad

### De 5 stegen i EDA:

Översikt - Hur ser datan ut? (shape, dtypes, head)
Städa - Saknade värden? Dubbletter? Fel datatyper?
Beskriva - Statistik (mean, median, std)
Visualisera - Grafer för att se mönster
Analysera samband - Korrelationer, grupperingar
